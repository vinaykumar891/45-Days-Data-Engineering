8. Constraints

## Key Takeaways

- Databases are used to store and organize data.
- Relational databases organize data into tables.
- DDL is used to define database structures.
- DML is used to manipulate data.
- Primary and Foreign Keys help establish relationships between tables.
- Constraints help maintain data integrity.
